# Company Context: CoParent Logic

## Product Overview

CoParent Logic is a web-based, AI-powered platform with two components:

1. **Professional Platform** — Designed for family law professionals to:
   - Draft conflict-resistant parenting plans
   - Extract objective behavioral insights from co-parent communications

2. **Mobile App (Parent-facing)** — For parents invited by family law professionals to:
   - View parenting plans
   - View calendars
   - Communicate inside the application
   - (Future) Add or edit calendar events inside the application

---

## Competitors

### OurFamilyWizard (OFW)
- Described as the **dominant platform**
- Allows professionals to view message threads, but lacks tools to analyze, summarize, or act on that data
- Professionals must spend hours on manual review
- Widely used and **court-ordered in all 50 states**
- Features include "ToneMeter" for rewriting messages

### TalkingParents
- Emphasizes **unalterable records**, secure messaging, and "Accountable Calling" with recordings and transcripts
- Focuses on being a "system-of-record" rather than an analytical tool

### AppClose
- Provides secure, timestamped records, messaging, and expense tracking

### 2houses
- Known for shared calendars, finance management, and a "schedule wizard" to help define custody arrangements
